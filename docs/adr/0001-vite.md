# 0001. Vite, keeping the REACT_APP_ prefix

Status: Accepted

## Context

The web app started on Create React App. The browser config already used `REACT_APP_*` names in `.env` and in `src/firebase/firebase-public.ts`.

## Decision

Build and dev-serve with Vite. `vite.config.ts` sets `envPrefix` to `REACT_APP_` so existing env files keep working. `npm run dev` is the Vite dev server. `npm run build` writes `build/`.

## Consequences

Tooling is Vite (`npm run dev`, `vite preview`). New client env vars still use the `REACT_APP_` prefix. Do not add a second prefix.
